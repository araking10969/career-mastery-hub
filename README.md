# Career Mastery Hub - 転職管理ツール

転職活動をシンプルに、かつ戦略的に。

「Career Mastery Hub」は、シンプルさと機能性を両立した転職活動用タスク・企業管理ツールです。

## 主な機能
- **ダッシュボード**: 今日のタスクと集中タイマー（25分）
- **選考管理 (Kanban)**: 企業ごとのステータスをドラッグ＆ドロップで管理
- **ロードマップ**: 自己分析から内定までのステップを視覚化
- **AI活用プロンプト**: 自己PRや面接対策に役立つテンプレートを即座にコピー
- **データ永続化**: ブラウザの `localStorage` で全ての情報を安全に保存

## 使い方
1. リポジトリをクローンまたはダウンロード
2. `index.html` をブラウザで開くだけで開始できます。

## 技術スタック
- HTML5 / Vanilla CSS
- Vanilla JavaScript
- Lucide Icons
